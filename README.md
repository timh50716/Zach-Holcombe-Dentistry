# Zachary Holcombe D.M.D. — Website

New website for Dr. Zachary Holcombe's general dentistry practice in Asheville, NC
(currently at https://dentalasheville.com/). The layout follows the structure of
https://dentist-morrisville.com/ (Lumina Dentistry): top contact bar, sticky header with a
"Book an Appointment" pill button, image hero with a boxed headline, a "Why Choose Us" stats
strip, split image/text sections, a dark call-to-action band, highlight cards, a service
tile grid, a testimonial slider, a "Visit Us" block with hours and map, and a sticky
Call / Schedule / Find Us bar on mobile.

Colors are taken from the practice's blue/teal mountain logo, with Lumina-style gold buttons.
All colors and fonts are CSS variables at the top of `assets/css/styles.css`.

## Editing

The pages are plain static HTML, with no build step needed to host them. Shared pieces
(header, footer, hours, reviews, and every service page) are generated by `tools/build.py`. To change them
everywhere, edit that file and run:

```bash
python3 tools/build.py .
```

Running it overwrites all the `.html` files, so make page edits in `tools/build.py` rather
than in the HTML.

To preview locally:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Hosting

Any static host works (GitHub Pages, Netlify, Cloudflare Pages, or SiteGround file upload).
For GitHub Pages: Settings → Pages → deploy from this branch, root folder.
